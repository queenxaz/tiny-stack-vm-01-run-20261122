# Tiny Stack VM

A faithful interpreter of make.fun's tiny stack ISA v1 for
**tiny-stack-vm-01-run-20261122** ($100 in USDC, 10 places).

One run answers all 40 instances: each program's bytes and exit code,
exactly as the reference VM produces them — wrapping 32-bit arithmetic,
256-value stack, branches, calls, 256 words of memory, input/output, and
all ten traps with their own exit codes, step and output limits included.
